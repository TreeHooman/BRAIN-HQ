# Context and account quota

War Room model cards, four orb arcs and LUTHUR's conversation page show Claude and ChatGPT/Codex separately. Each shows last-turn context tokens/capacity, five-hour percentage used and reset time when supplied. Claude also shows weekly usage on the conversation page. Readings distinguish current, stale, awaiting-reset-update and unavailable. Missing telemetry is never assumed to be zero. Provider quota and conversation context are different measurements.

ChatGPT/Codex account usage is read through the signed-in local Codex app-server: initialize, initialized and account/rateLimits/read only. No thread/turn is started, credentials are not opened, API-key environment overrides are removed, MCP servers suppressed, and the bounded subprocess is terminated after the response. Results are deduplicated/cached for 60 seconds and exposed only behind existing PIN protection. Prefer rateLimitsByLimitId over the legacy view; render every supplied 300-minute bucket separately. usedPercent is already percentage (1 means 1%, not 100%); reset timestamps are converted from seconds. Other durations are not relabeled five hours. Account-wide readings include Codex use outside LUTHUR. Failed refreshes explicitly mark cached values stale.

Official schema reference: https://learn.chatgpt.com/docs/app-server#6-rate-limits-chatgpt . Local read-only probe succeeded and supplied 300-minute and weekly windows. The live percentages are not hardcoded.

Codex conversation context comes from the known LUTHUR session's local token_count telemetry: info.last_token_usage.total_tokens and model_context_window. Cumulative turn totals are never substituted. Only a validated UUID's matching rollout file is read, within the sessions directory, with a bounded tail; no other conversations or credential files are returned. Latest context is retained across provider switching and deleted when a new Codex turn has no telemetry. Missing telemetry/window stays unavailable. Context updates after completed turns; quota polls independently.

Claude quota remains a CLI snapshot, not live account polling. Show its report timestamp and mark it stale after five minutes or expired at reset; unknown reset/percentage stays unavailable. Preserve fractional utilization units and the event timestamp. Context sums the last assistant call's input and cache tokens and chooses that assistant model's reported capacity. Missing metadata clears old values; Code no longer invents a 200k capacity or retains another provider's context/rate.
