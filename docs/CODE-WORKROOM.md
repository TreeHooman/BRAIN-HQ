# LUTHUR coding manager

Code → Talk to LUTHUR → choose the project and repository. The existing workroom for that repository is reused. Existing coding chats also use the manager flow after their next request; imported conversation seeds compact notes, not an indefinitely resumed CLI transcript.

LUTHUR handles simple requests in one call. When worthwhile, he proposes one or two focused assignments, run sequentially by the server with inherited repository access, permission ceiling and selected provider/model policy. Each worker has a concise assignment and bounded prior result. No recursive delegation; native agent tools are disabled for managed CLI runs and the Code MCP cannot queue background followups. A final manager pass checks and integrates successful worker results. At most four model runs per owner turn; failure/limit/auth/stop/time expiry halts the chain without automatic retries or provider escalation. Workrooms themselves have at most two active turns across Code. Each turn shares the configured overall time limit.

Auto uses Luna 6 / Haiku for casual chat and Sol 6.1 / Sonnet for coding work, coding continuation, workers and review. Explicit manual model choice and Astra/Opus authorization remain intact. Worker text cannot authorize a premium model.

Notes live under data/code/workrooms/<session-id>: BRIEF.md, PLAN.md, STATUS.md, REPORT.md, HANDOFF.md and up to two WORKER-N.md files. Open Workroom notes in the conversation to see the published brief, status, plan, report and durable handoff. Notes contain reported work and evidence, not private reasoning. Handoff stays compact and survives casual chat. Each invocation has fresh CLI context: relevant repository notes, bounded handoff and current request. Full transcript replay and automatic post-turn summarizer calls are removed from managed Code work. Changed-file outcomes are logged directly to the project; the manager remains responsible for updating relevant repository Markdown plans and handoffs.

Verified through isolated fake CLIs on both providers, bounded-chain/failure/cancellation/premium tests, browser repository reuse/notes and model-routing regressions. Local Codex feature inventory confirms both agent feature switches. No real model calls, edits by generated workers, or physical voice sessions were used in verification. Restart LUTHUR and refresh to activate the backend changes.
