# Frontier Plan

**What it is:** the long-range plan for scaling LoanCentral (and maybe Borrow Fast) once survival is secured.

**Status:** planned. It starts properly with Phase 5 (Q2 2027).

**Ground rules (already decided):**
- Survive → grow → monetize. Money model undecided; lawyer first.
- Never sell anything about borrowers; no paywall on borrower data or health scores (FCRA).
- Verification/flair must never be paid (Mod Code of Conduct rule 5).

**Ideas parking lot:**
- Lender onboarding funnel, monthly stats post, request pages.
- Multi-platform: Reddit + Discord + site with a shared login.
